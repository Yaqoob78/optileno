# Optileno - Premium SaaS Explainer Video Script (Remotion)
**Target Length:** ~30-40 seconds
**Aspect Ratio:** 16:9 (1920x1080) for web/YouTube, or 9:16 (1080x1920) for TikTok/Reels depending on preference. (We will default to 16:9 for the desktop presentation).
**Visual Style:** Dark, futuristic, clean. Deep blacks, glowing grid lines, gold accents (`#FBBF24`), smooth Apple/Stripe-like transitions.
**Audio:** Hard-hitting electronic beats, minimal but sharp UI *click/swoosh* sound effects.
